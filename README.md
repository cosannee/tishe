# тише.

Адаптивный сайт с единым дизайном для телефона, планшета и компьютера: свободный план, направления, привычки, вдохновение, разговор и бережное наблюдение за едой. Установка через App Store не требуется. Дизайн и принципы описаны в [DESIGN.md](DESIGN.md).

## Что работает

- Личный план без расписания по часам, отметки звёздочкой, направления, недельные привычки, «Моё поле», «Когда-нибудь» и «Мой путь».
- Вдохновение: мысли и фотографии. После входа записи сохраняются в личном аккаунте Supabase, фотографии — в закрытом хранилище.
- На GitHub Pages ИИ для разговора, поддержки и приблизительного разбора питания подключён через Cloudflare Worker. Ключ хранится только как секрет Worker и не передаётся на GitHub Pages. При недоступности сервера приложение показывает локальный ответ.
- Настройки целей, «зачем мне это», пяти стилей поддержки и памяти. Можно выбрать бережный, дружеский, игривый, дерзкий или прямой тон и сразу увидеть пример. Память передаётся ИИ только при включённой отметке. Разговоры не добавляются в память автоматически.
- Экспорт данных в JSON, удаление данных и явный перенос записей из прежней версии браузера.

## Запуск и тесты

Нужны Python 3, Node.js 22 и pnpm 11.

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm test
python3 -m http.server 4173 --directory public
```

Локальный просмотр доступен на `http://localhost:4173`. Публичный сайт открывается напрямую на [GitHub Pages](https://cosannee.github.io/tishe/) из корневого `index.html`, который загружает файлы `public/`. ИИ для GitHub Pages обслуживает [Cloudflare Worker](cloudflare/README.md), адрес которого указан в `ai-config.js`. В локальном просмотре серверный ИИ недоступен. Закрытая версия Sites имеет отдельный серверный маршрут ИИ. Локальный `.env.local` игнорируется Git и не используется в браузере. Код CI проверяется GitHub Actions при каждом push и pull request.

## Подключение Supabase

Для GitHub Pages подключён отдельный проект Supabase `tishe_app` в организации `tishe`. Браузер использует только публичный ключ из `supabase-config.js`; ключ администратора в сайт добавлять нельзя. [Схема и политики доступа](supabase/schema.sql) применены к проекту. Адрес сайта `https://cosannee.github.io/tishe/` указан в Auth URL Configuration. После входа по одноразовой ссылке старые записи из браузера переносятся только по явному нажатию кнопки. Фотографии лежат в закрытом bucket; таблица и файлы ограничены правилами владельца.

## Данные и доступ

Версия Sites ограничена доступом владельца и хранит записи локально. На GitHub Pages после входа данные хранятся в Supabase с политиками доступа для каждого пользователя. Cloudflare Worker проверяет сессию Supabase перед запросом к ИИ. Содержимое старой версии остаётся в localStorage до явного переноса; после успешного переноса локальная копия удаляется. Сессия входа хранится браузером. Перед приглашением других людей нужно проверить изоляцию на двух отдельных аккаунтах и сценарии восстановления из резервной копии; см. [architecture/README.md](architecture/README.md).

## Откат

Исходный коммит до ТЗ 2.0 сохранён под локальным тегом `before-tishe-v2`. Предыдущие публикации доступны в истории версий Sites. Перед откатом можно скачать данные из настроек. Формат локальных записей и ключ хранилища не менялись.
