# тише.

Адаптивный сайт с единым дизайном для телефона, планшета и компьютера: свободный план, направления, привычки, вдохновение, разговор и бережное наблюдение за едой. Установка через App Store не требуется. Дизайн и принципы описаны в [DESIGN.md](DESIGN.md).

## Что работает

- Личный план без расписания по часам, отметки звёздочкой, направления, недельные привычки, «Моё поле», «Когда-нибудь» и «Мой путь».
- Вдохновение: мысли и фотографии. Фотографии и записи сохраняются в текущем браузере.
- ИИ для разговора, поддержки и приблизительного разбора питания. Ключ хранится только на сервере Sites. Если ИИ недоступен, приложение показывает локальный ответ и сообщает об этом.
- Настройки целей, «зачем мне это», пяти стилей поддержки и памяти. Можно выбрать бережный, дружеский, игривый, дерзкий или прямой тон и сразу увидеть пример. Память передаётся ИИ только при включённой отметке. Разговоры не добавляются в память автоматически.
- Экспорт данных в JSON и удаление данных текущего браузера.

## Запуск и тесты

Нужны Python 3 и Node.js 22. Установка пакетов не требуется.

```sh
python3 scripts/build.py
node --test tests/*.test.cjs
python3 -m unittest discover -s tests -p '*test.py'
python3 -m http.server 4173 --directory public
```

Локальный просмотр доступен на `http://localhost:4173`. В нём серверный ИИ недоступен; для проверки ИИ нужна опубликованная версия Sites с серверным секретом `OPENAI_API_KEY`. Локальный `.env.local` игнорируется Git и не используется в браузере. Код CI проверяется GitHub Actions при каждом push и pull request.

## Данные и доступ

Опубликованный сайт ограничен доступом владельца через Sites. Серверный маршрут ИИ требует подтверждённой личности посетителя; запросы без неё отклоняются. Дела, фото, разговоры и настройки пока хранятся только в localStorage текущего браузера. На общем устройстве они видны другим людям с доступом к этому браузеру. Синхронизации между устройствами и отдельных серверных хранилищ пользователей пока нет — до приглашения других пользователей нужен следующий этап из [architecture/README.md](architecture/README.md).

## Откат

Исходный коммит до ТЗ 2.0 сохранён под локальным тегом `before-tishe-v2`. Предыдущие публикации доступны в истории версий Sites. Перед откатом можно скачать данные из настроек. Формат локальных записей и ключ хранилища не менялись.
