# Тихий ритм · дизайн v0.1

Рабочее название можно заменить. Источник: доступные сообщения чата «План переезда в Европу» и уточнения текущего запроса. Более ранние вложения и фото инструмент не вернул; не подменяем их чужими референсами.

- Фон #f7f6f0, графит #343630. Golos Text с sans-serif fallback.
- Воздух, небольшие спокойные заголовки, списки без внешних рамок, тонкие контурные кнопки.
- Звёздочка из предоставленного пользователем star.svg вместо галочек. Никаких летящих звёзд и праздничной анимации внутри.
- На входе рисованный цветок: три палитры, случайный выбор при загрузке и смена по нажатию.
- Внутри цвет остаётся в маленьких полупрозрачных подписях снизу (#af4d37 / #416b95) и редких звёздочках на фото. Фото без ярких рамок.
- Сегодня, гибкий план, произвольные направления, развитие/недельные привычки, вдохновение, два раздела поддержки, настройки.
- Никакого расписания по часам, наказания за пропуск, обнуления серий или давления на чувство вины.
- Возможность отдыха равноправна маленькому шагу.
- Настройки: имя, история, цели, «зачем» для каждого направления, пять стилей поддержки (бережно, по-дружески, игриво, дерзко, прямо), редактируемая память и явное разрешение её использования. Даже игривый и дерзкий тон не превращают разговор о еде в оценку или критику.
- Телефон, планшет и компьютер используют одну тихую композицию с нижней навигацией. На широком экране она становится просторнее без рамки телефона; значок «по-ле» и путеводная звёздочка остаются на месте.
- Уважать reduced motion, использовать понятные подписи кнопок, фокус клавиатуры, системные диалоги и проверку форм.

Граница текущей версии: данные остаются в браузере; ИИ подключён через сервер Sites, но отдельные серверные хранилища пользователей и синхронизация ещё не готовы. Нет имитации защищённого хранения данных.

Обновление: мобильная композиция опирается на предоставленный скриншот исходника: «Сегодня» с фокусом и ритуалами, «Неделя» с пятью отметками, список направлений, нижняя навигация с пиктограммами. Начальный цветок перерисован по предоставленному GIF в шести цветовых вариантах с ручными прожилками.

Новый режим «Дофаминовое приложение» по желанию добавляет спокойные акценты: голубой, терракота, мягкий персиковый и шалфейный. Символы стрелок и эмодзи удалены из видимых текстов. Начальный экран показывается при каждом открытии; цветы меняются по нажатию.
